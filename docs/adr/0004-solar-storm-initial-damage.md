# ADR 0004：太阳风暴初始伤害对齐初始陨石

- 状态：已采纳
- 日期：2026-10-25

## 背景

太阳风暴（Solar Storm）L1 的基础伤害是 40，而开局生成的大型岩石陨石生命值是 50
（`KnobsAsteroids.large.hp = 50`，岩石类型倍率 1）。因此开局一次太阳风暴命中后，目标还剩
10 HP，必须等下一次落雷才能清掉。需求是让初始太阳风暴“刚刚好一发打死一个初始陨石”。

## 决策

把 `KnobsWeapons.solarStorm` 的默认伤害从 `40f` 改为 `50f`。

- 太阳风暴 L1 的 `getDamage` 倍率是 1.0，`GameState.damageMultiplier` 初始也是 1.0，所以
  开局落雷伤害正好等于 50，目标生命值归零。
- 暴击、Momentum 等加成仍然可以超过 50；这只影响“至少能一发打死”，不影响“刚刚好”的
  基础值。
- 不修改陨石生命值、太阳风暴半径、目标数量或冷却。陨石生命值会随生存时间缩放，金属陨石
  仍然是 100 HP，所以 50 点伤害只在开局对普通大型岩石构成一发击杀，不会变成全程清场。
- 敌机 Scorcher、舰队等复用同一个武器旋钮，因此它们的太阳风暴也同步变为 50 点。这与
  ADR 0001 “敌方复用同一批武器类”的镜像规则一致，不新增玩家专属伤害分支。

## 后果

- 开局太阳风暴对普通大型岩石：一次命中正好击杀，分裂逻辑照常触发。
- 对金属陨石（100 HP）仍需两次；对已经历生命值缩放的陨石不再保证一发。
- 太阳风暴的实际 DPS 提高 25%（40 → 50），属于明确的平衡性增强；如果后续觉得过强，应
  优先回调该旋钮，而不是在武器代码里写特例。
- 新增测试锁定“太阳风暴 L1 基础伤害 == 初始大型岩石生命值”，避免两处数值再次漂移。

## 备选方案

- **改成 51 或 55**：能一发打死，但会掩盖“初始陨石 50 HP”这个基准，后续微调时容易误判；
  50 更符合“刚刚好”。否决。
- **降低初始陨石生命值到 40**：会同时改变所有武器对开局陨石的击杀阈值，影响面远大于只改
  太阳风暴。否决。
- **在太阳风暴代码里对开局陨石加特判**：制造第二套伤害规则，且无法解释为什么同一武器对
  同类目标伤害不同。否决。
